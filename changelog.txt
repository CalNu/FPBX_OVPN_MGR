2.61
• Added "Rebuild Config Selected" (package manager) and "Rebuild Config, Keep Keys" (after a server address/port change): rewrites vpn.cnf and re-tars the package without revoking - each phone keeps its key, certificate and cipher.
• Fixed Rebuild All and Revoke & Rebuild Selected resetting every package's cipher to AES-128-CBC; the package's existing cipher is now preserved.
• Added a notice under Server Public IP / Host when a hostname is entered: some Yealink phones hang on "obtaining IP address" when vpn.cnf uses a hostname; use an IP or set the phone to a static IP.
• Client vpn.cnf no longer includes data-ciphers / data-ciphers-fallback when the cipher is AES-128-CBC (legacy phones reject them).
• Fixed some graphical alignment

• Fixed corrupted text on Cipher selections and notices.
• Change Local IP and Public IP buttons to pure icons with hoverover text
• Fixed bug where starting the service wasn't starting Kernel IP Forwarding (net.ipv4.ip_forward) unless you change the host or cidr.
• Sped up setup-root.sh script by removing unnecessary chown's

2.50
• Fixed phones on VPN not accessible using their lan ip, only their OpenVPN IP (push {serverIP} 255.255.255.255).
• Fixed reboot bug requiring running setup-root.sh script each reboot.
• Added permissions in setup-root.sh script to allow yealink_epm module to scan OpenVPN subnets for yealink MAC addresses.
• Added cipher selection labeling with a warning for phones that don't work with stronger ciphers and using weak ciphers for newer models.
• Fixed port number change not sticking.
• OpenVPN server config and PKI are anchored to the real AMPWEBROOT/PhoneSettings/openvpn directory.
• Installer no longer creates PhoneSettings -> /tftpboot.
• Admin UI and privileged scripts refuse a symlinked PhoneSettings directory to prevent VPN data from being written under /tftpboot.
• Existing installations with PhoneSettings symlinked to /tftpboot require a one-time, backed-up migration before reinstalling/restarting the module.
• Provisioning builder Extension and Phone MAC suggestion lists now exclude identifiers already present in generated OpenVPN/keys archives; displays a helpful note when no unused suggestions remain.
• Added root-setup integration to derive the OpenVPN client subnet from legacy-vpn.conf and add it idempotently to Fail2Ban [DEFAULT] ignoreip, preserving existing entries. Performs a config test and reloads active Fail2Ban; skips cleanly if Fail2Ban is not installed.
• Automatically merges the OpenVPN client pool into FreePBX Asterisk SIP Settings > NAT > Local Networks, preserving existing entries and triggering a FreePBX reload. Syncs during root setup and whenever VPN subnet settings are saved.
• Fixed reboot persistence: setup-root now installs/enables ovpn-mgr-openvpn.service so the OpenVPN daemon starts automatically after boot, ordered after network-online and the VPN NAT restore service. NAT restoration is ordered after common firewall services; setup reports service-start failures with journalctl diagnostics.
